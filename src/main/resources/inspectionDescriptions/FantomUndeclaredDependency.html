Reports using x and using x::Type when pod x is not in the depends list of the pod's build.fan. The Fantom compiler rejects such a using.

The quick fix adds "x 1.0" to depends. The version comes from the installed x.pod, else from the version in the pod's source build.fan.

Not reported for sys, for the file's own pod, when there is no build.fan, or when depends is not a literal list of strings.
