Reports an identifier that does not resolve to a declaration in the project or in the Fantom installation.

For an unknown type name the quick fix adds a using pod::Name line when a pod of the installation has a Name.fan source file.

Not reported: dynamic calls (->x), slots on a receiver whose type is unknown, generic placeholders such as V in |V item|, facet values, and everything when no Fantom installation is configured.

Configure the Fantom installation under Settings | Languages & Frameworks | Fantom.
